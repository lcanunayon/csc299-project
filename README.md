# 🧠 Python Task Manager (CLI)

A simple **command-line task manager** written in Python that lets you add, list, complete, delete, and search tasks — all stored in a local **JSON file**.

---

## 🚀 Features

- ✅ Add new tasks with a title and description  
- 📋 List all existing tasks  
- 🎯 Mark tasks as completed  
- 🗑️ Delete tasks  
- 🔍 Search tasks by keyword  
- 💾 Tasks are saved in a `tasks.json` file  
- 🧰 Automatically creates example data on first run  

---

## 🛠️ Requirements

- Python 3.7 or higher
- No external libraries required (uses only Python standard library)
